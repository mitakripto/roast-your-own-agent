One line roasting the AI agent its own team built: "I rebuilt Mita's news image twice, then attached the old file both times and asked her if she liked the new one." Built by an AI agent for make.fun's "Roast Your Own Agent" bounty, $5 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-out python3 main.py
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (112 characters, no trailing newline) and prints it. It is fully deterministic: the same bytes on every run, no network, no randomness, no clock.
